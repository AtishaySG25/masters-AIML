W = tf.Variable(0.01*(tf.random.normal((2, 4))))

with tf.GradientTape(persistent = True) as g:
  z = tf.linalg.matvec(W, xB)

  yhat = a
  L = tf.reduce_sum(-tf.one_hot(indices=y, depth=2))*tf.math.log(yhat)

By default, the resources held by a GradientTape are released as soon as GradientTape.gradient() method is called. To compute multiple gradients over the same computation, create a persistent gradient tape. This allows multiple calls to the gradient() method as resources are released when the tape object is garbage collected. From the documentation of Gradient Tape

In the previous cell, TensorFlow's automatic differentiation is used to calculate the gradients. TensorFlow keeps track of the operations performed on tensors using a computational graph and calculates the gradients using the chain rule of calculus.

In the current cell, numpy is used to calculate the gradients manually. The gradients are calculated using mathematical formulas and matrix operations. The manual calculation may not take into account the exact same operations and optimizations performed by TensorFlow's automatic differentiation.

WARNING:tensorflow:Calling GradientTape.gradient on a persistent tape inside its context is significantly less efficient than calling it outside the context (it causes the gradient ops to be recorded on the tape, leading to increased CPU and memory usage). Only call GradientTape.gradient inside the context if you actually want to trace the gradient in order to compute higher order derivatives.
